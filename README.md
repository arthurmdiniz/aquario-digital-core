# Missão: Controle de Qualidade da Água do Aquário

O `aquario-digital-core` tem como missão verificar se os principais parâmetros
da água do aquário estão dentro dos níveis ideais para a vida aquática.

## Camadas do ambiente

- **develop**: ambiente de desenvolvimento, usado para implementar novas funcionalidades
- **stage**: ambiente de validação, Usado para testar a versão integrada em condições próximas da produção
- **main**: ambiente principal e estável. Contém apenas versões validadas e prontas para uso em produção.
